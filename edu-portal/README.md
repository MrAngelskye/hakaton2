# Образование рядом — MVP сайтов школ и детских садов

Публичные сайты на русском и казахском, закрытые кабинеты сотрудников и управление сетью организаций. Всё запускается одной командой Python, без установки внешних библиотек.

## Запуск

Нужен Python 3.10 или новее. На Windows дважды нажмите `start-portal.cmd`. На любой системе из этой папки:

```sh
python server.py
```

Откройте `http://127.0.0.1:4173/`. Не открывайте `dist/index.html` как отдельный файл — для API и базы нужен сервер. Остановка: Ctrl+C.

При первом запуске создаётся `data/edu.sqlite3`: 12 вымышленных организаций, двуязычные тексты, новости, демонстрационные файлы и 6 тестовых аккаунтов. Повторный запуск сохраняет ваши изменения. При обновлении старой базы новые таблицы создаются автоматически; ваши тексты не заменяются демонстрационными переводами. Недостающие новые поля можно заполнить через кабинет.

Отдельная папка хранения:

```sh
python server.py --port 4173 --data-dir /path/to/portal-data
```

## Что есть в MVP

- Каталог и опубликованные сайты доступны всем без регистрации.
- RU/ҚАЗ: переключение интерфейса и отдельно сохранённые тексты. При отсутствии перевода отображается сообщение об этом.
- Общие разделы: об организации, родителям, новости, документы и контакты с телефоном.
- Для школы: обучение и программы. Для садика: возрастные группы и режим дня.
- Сотрудник меняет только свою организацию; администратор создаёт организации и назначает аккаунты.
- Сайт может быть черновиком: тогда его содержание скрыто от публичной части.
- Новости можно создавать, редактировать, публиковать, архивировать и возвращать из архива. Дата подставляется текущая; отложенной публикации нет.
- Загружаются реальные PDF/TXT до 8 МБ. Черновики и архивные файлы закрыты от публичного скачивания; публикация открывает файл всем.
- Кабинет показывает наличие основных сведений и журнал действий. Процент заполненности не подтверждает достоверность или юридическую готовность сайта.
- Мобильные страницы и меню, увеличение текста и клавиатурная навигация.

Кабинет сотрудников пока на русском. Один документ имеет один файл; для разных файлов RU/ҚАЗ можно создать отдельные записи.

## Доступы для локального показа

Общий демонстрационный пароль: `Demo2026!`. Он известен из исходников и показан в демо-интерфейсе. Эти доступы нельзя использовать для реального размещения.

| Логин | Роль входа | Кабинет |
| --- | --- | --- |
| `teacher-garden` | Сотрудник | Детский сад «Солнышко» |
| `teacher24` | Сотрудник | Школа №24 |
| `teacher7` | Сотрудник | Школа №7 |
| `student24` | Ученик / родитель | Чтение своей организации через защищённый API |
| `student7` | Ученик / родитель | Чтение своей организации через защищённый API |
| `admin` | Админ | Все организации и пользователи |

Публичные утверждённые материалы доступны этим пользователям и без входа, включая сайты других организаций. Ограничение своей организации применяется к закрытым API и редактированию. Для чтения публичных страниц детские аккаунты создавать не нужно.

Можно задать `EDU_DEMO_PASSWORD` перед **первым** созданием новой демонстрационной базы. Тогда форма не показывает стандартное автозаполнение. Это не заменяет полноценное управление паролями: смена, восстановление и отключение аккаунта пока не реализованы.

## Проверки

```sh
python -m unittest discover -s tests -v
```

19 HTTP-тестов: прежняя изоляция закрытых кабинетов, публичная часть, две версии текста, садики, черновики, публикация, архив, загрузки, CSRF, параллельные попытки входа и журнал. Отдельная тестовая база удаляется после проверки; рабочие данные не затрагиваются. Можно задать `EDU_TEST_DIR` для временных тестовых файлов.

## Границы версии

Это локальный MVP для показа. Сервер `http.server` не предназначен для production; сеть пока не установлена на сервере области. Не проверены нагрузка на 600 организаций, полный аудит безопасности и соответствие обязательным разделам официального сайта.

Не подключены зачисление, электронная очередь, оплата, посещаемость, eGov и персональные сведения детей. Файлы проверяются по типу, размеру и сигнатуре PDF; антивируса нет. Журнал хранится в базе и не является неизменяемым аудитом. Изменение основного содержания сайта применяется сразу после сохранения; отдельного согласования изменений опубликованного сайта нет.

Размещать для реального использования можно только после подготовки: отдельные пароли, отключение демо, production-сервер, HTTPS, резервные копии и проверка восстановления, защита входа, антивирусная проверка файлов, обучение сотрудников и согласование содержания.

Основной план и сценарий показа находятся в `../docs/`. Скриншоты и отчёт проверок — в `../artifacts/`.
