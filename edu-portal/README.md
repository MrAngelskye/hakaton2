# Образование рядом — MVP с тремя ролями

Русскоязычный адаптивный портал организаций образования. Минималистичный интерфейс для учеников, учителей и администратора области.

## Вход и права

| Роль | После входа | Возможности |
| --- | --- | --- |
| Ученик | Страница закреплённой школы | Читать её информацию, новости и документы |
| Учитель | Страница закреплённой организации | Читать и редактировать её страницу, публиковать новости |
| Администратор | Каталог всех организаций | Добавлять и редактировать организации, создавать аккаунты учеников и учителей, менять их привязку |

Ученик и учитель не получают каталог, сведения, новости или документы других организаций. Ограничение проверяет сервер при каждом запросе. Выбор кнопки «Админ» не меняет роль аккаунта. После смены привязки администратором действующие сеансы пользователя завершаются.

## Запуск

Нужен Python 3.10 или новее. Внешние библиотеки, установка пакетов и сборка не требуются.

На Windows откройте `start-portal.cmd` и оставьте окно сервера открытым. Скрипт использует Python из среды Codex, если он доступен, либо установленный Python.

На любой системе из папки проекта:

```sh
python server.py
```

Откройте <http://127.0.0.1:4173>. Остановить сервер можно сочетанием Ctrl+C в его окне. Открытие `dist/index.html` напрямую или размещение только папки `dist/` не обеспечивает работу входа и базы.

Общий демонстрационный пароль: `Demo2026!`. Эти аккаунты предназначены только для знакомства с MVP.

| Логин | Кнопка входа | Привязка |
| --- | --- | --- |
| `student24` | Ученик | Школа № 24 |
| `student7` | Ученик | Школа № 7 |
| `teacher24` | Учитель | Школа № 24 |

На экране входа есть кнопка заполнения тестового аккаунта выбранной роли. Организацию ученик или учитель при входе не выбирает.

## Что работает

- Три варианта входа, проверка пароля и роли, серверные сеансы и выход.
- Автоматическое открытие закреплённой организации.
- Отдельное пространство ученика и кабинет учителя без чужих организаций.
- Общий каталог администратора: поиск, типы, районы, страницы, карточки и список.
- Добавление организаций, аккаунтов и изменение привязки пользователей.
- Сохранение страниц и новостей в общей SQLite-базе; изменения доступны другим аккаунтам той же организации после обновления страницы.
- Скачивание демонстрационных TXT-документов своей организации.
- Мобильное меню, увеличение текста и клавиатурная навигация.
- Обновление открытых вкладок при входе или выходе в другой вкладке современного браузера.

## Данные и сервер

При первом запуске создаётся `data/edu.sqlite3` с 12 демонстрационными организациями и 6 тестовыми аккаунтами. Последующие запуски сохраняют изменения. База и начальные данные не раздаются браузеру как публичные файлы.

Можно задать другую папку хранения и порт:

```sh
python server.py --port 4173 --data-dir /path/to/portal-data
```

Пароли хранятся как PBKDF2-хеши с индивидуальной солью. Сеансы используют HttpOnly-cookie, серверный срок действия и CSRF-токен для изменений. Прямые API-запросы также проверяют роль и организацию.

Это локальный работающий MVP. На сервер области он ещё не установлен. Для рабочего размещения нужны HTTPS и reverse proxy, защищённое хранение и резервное копирование базы, замена известных тестовых аккаунтов и подготовка серверного запуска под нагрузкой. Параметр `--secure-cookies` включается при работе через HTTPS. Стандартный HTTP-сервер Python используется здесь для прототипа.

Все организации, контакты, документы и новости — примеры. Загрузка файлов, журнал действий, восстановление паролей, модерация и интеграции пока не реализованы. Около 600 организаций — целевой масштаб исходной задачи; эффект уточняется заказчиком. Бесплатное использование организациями — целевая модель.

## Проверка прав

```sh
python -m unittest discover -s tests -v
```

9 интеграционных тестов проверяют вход, ограничения чтения и записи, запрет подмены роли, права администратора, смену привязки, сохранение данных, CSRF и завершение сеанса.

## Структура

- `server.py` — сервер, API, проверка доступа и SQLite.
- `seed.json` — начальные демонстрационные данные; только для сервера.
- `dist/` — интерфейс и оригинальная SVG-иллюстрация.
- `tests/test_access.py` — проверки прав через HTTP.
- `start-portal.cmd` — запуск на Windows.

В архиве нет рабочей базы, сеансов, сторонних зависимостей или реальных персональных данных.
