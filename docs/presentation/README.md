# BilimBir — презентация для заявки

8 слайдов: задача проекта, решение, школы и садики, кабинеты, стадия MVP, команда и дальнейшие шаги.

- [PDF для просмотра](BilimBir.pdf).
- [Редактируемая презентация PowerPoint](BilimBir.pptx).

Все функции описаны по демонстрационному MVP. Показатели 32 серверных и 15 клиентских тестов относятся к техническим проверкам, а не к количеству пользователей. Реальные пилоты и подтверждённый PMF не заявляются. Снимки интерфейса содержат вымышленные данные.

Команда состоит из трёх участников. Все участники работают full-time.
