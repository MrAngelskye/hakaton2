# Проверки макета MVP

Проверено 12 октября 2026 года на Windows и Python 3.12.14. Использованы только вымышленные организации, аккаунты и документы. Со школами / садиками связи не было; их системы и базы не подключались.

## Результат

После пользовательского и технического аудита прошли **32 HTTP-теста и 15 проверок клиентского кода**. Повторные браузерные проверки и исправления описаны в [USER-DEVELOPER-AUDIT.md](USER-DEVELOPER-AUDIT.md). Далее сохранены результаты исходной проверки MVP, предшествовавшей этому аудиту.

- 19 HTTP-тестов прошли: 9 прежних и 10 новых. Команда из корня: `python -m unittest discover -s edu-portal/tests -v`.
- JavaScript прошёл `node --check edu-portal/dist/app.js`.
- В браузере проверены каталог без входа, фильтр четырёх садиков, RU/ҚАЗ, возрастные группы, режим дня и раздел родителям.
- Проверены вход сотрудника садика, сохранение раздела, создание двуязычного черновика новости, редактирование, публикация и открытие статьи на публичной странице.
- Проверена реальная загрузка учебного TXT через форму, его публикация и скачивание с публичной страницы. Скачанный файл побайтно совпал с `tests/fixtures/public-notice.txt`.
- SHA256 скачанного файла: `dd4ab96ed96aa4ec3d8f5ece35b6d869ee9e5e7c5e3155ae37e6ea0d1b811e42`.
- Проверена мобильная страница садика при ширине 390 пикселей: в проверенном состоянии горизонтального переполнения страницы нет.
- Проверены кабинет администратора, создание вымышленного садика как черновика, список и форма управления аккаунтами, школьный раздел «Обучение и программы» на RU/ҚАЗ.

Новые автоматические проверки подтверждают, что черновики сайтов, новостей и документов не выдаются публичным API, сотрудники не редактируют чужую организацию, невалидный CSRF получает 403, а параллельные ошибочные входы корректно учитываются ограничителем.

GitHub Actions успешно выполнил HTTP-тесты и проверку JavaScript на Python 3.10 и 3.13 (Ubuntu): [запуск 38275774962](https://github.com/MrAngelskye/hakaton2/actions/runs/38275774962), проверенный коммит `865e6d320ebfc7194c0c36a20b2795ebb78d2ef1`. Исходники загружены в ветку `codex/mvp-kindergartens`.

Архив исходников проверен на целостность и запуск из чистой распаковки: публичный каталог содержит 12 организаций, включая 4 садика; главная страница, JavaScript и CSS возвращают HTTP 200. Рабочая база, Git и файлы настроек в архив не включены.

## Границы проверки

Это макет работы сервиса с локальным сервером и учебными данными. Реальные интеграции, production-размещение, 600 организаций, восстановление рабочей базы и полный аудит безопасности / доступности не проверялись. Сигнатура PDF проверяется, но полноценный разбор PDF и антивирусная проверка не выполняются.

Все файлы загрузок хранятся в локальной SQLite-базе. Архив исходников и Git исключают рабочую базу. Журнал — обычная таблица, которую может изменить администратор базы; он не является неизменяемым аудитом.
